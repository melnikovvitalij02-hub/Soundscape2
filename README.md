# 🪐 SOUNDSCAPE V2 — YouTube Music

Это версия проекта с более фиолетовым неоновым дизайном.

Музыка работает по схеме:

SOUNDSCAPE
→ твой Node.js сервер
→ YouTube Data API
→ найденные видео
→ официальный YouTube IFrame Player
→ ▶ воспроизведение внутри приложения

Пользователю НЕ нужно вставлять YouTube-ссылку.

---

## 1. Что изменено

### Дизайн
- больше фиолетового и розово-фиолетового неона;
- SOUNDSCAPE стал ярко-белым и лучше читается;
- добавлено неоновое свечение;
- активные кнопки стали фиолетовыми;
- карточки и плеер получили фиолетовую подсветку;
- мобильный вид сохранён.

### Музыка
- убран iTunes из музыкального раздела;
- убран Piped;
- убрано поле для вставки YouTube-ссылки;
- поиск идёт через YouTube Data API на сервере;
- нажимаешь на найденный трек — он запускается через YouTube Player;
- есть Play/Pause;
- есть предыдущий/следующий;
- есть повтор;
- есть громкость;
- есть перемотка;
- после окончания можно перейти к следующему найденному треку.

# 2. Что нужно установить

Нужен Node.js версии 18 или новее.

Скачивать:

https://nodejs.org/

Лучше брать LTS.

После установки открой CMD и проверь:

```text
node --version
```

и:

```text
npm --version
```

Если обе команды показывают версии — всё нормально.

---

# 3. Распакуй архив

Распакуй этот архив, например:

```text
C:\SOUNDSCAPE
```

Внутри должны лежать:

```text
C:\SOUNDSCAPE\
│
├── server.js
├── package.json
├── README.md
│

    └── index.html
```

# 4. Установи зависимости

В адресной строке Проводника напиши:

```text
cmd
```

и нажми Enter.

```text
npm install
```

Подожди завершения установки.

---

# 5. Получи YouTube API key

Открой:

https://console.cloud.google.com/

Создай Google Cloud Project, например:

```text
SOUNDSCAPE
```

Затем:

1. APIs & Services
2. Library
3. Найди `YouTube Data API v3`
4. Нажми Enable
5. Перейди в Credentials
6. Create credentials
7. API key

Google покажет длинный ключ.

Пример формата:

```text
AIzaSyXXXXXXXXXXXXXXXXXXXXXXXX
```

Это только пример.

---

# 6. НЕ вставляй API key в index.html

Ключ должен оставаться на сервере.

Не делай:

```javascript
const API_KEY = "твой ключ";
```

в `index.html`.

Наш проект использует переменную окружения:

```text
YOUTUBE_API_KEY
```

---

# 7. Запуск в Windows CMD

В CMD, находясь в папке проекта, напиши:

```bat
set YOUTUBE_API_KEY=ТВОЙ_НАСТОЯЩИЙ_КЛЮЧ
```

Например:

```bat
set YOUTUBE_API_KEY=AIzaSyXXXXXXXXXXXX
```

Потом:

```bat
npm start
```

Должно появиться:

```text
SOUNDSCAPE запущен: http://localhost:3000
```

# 9. Проверка музыки

1. Открой раздел `🔊 Музыка`.
2. В поиске напиши, например:

```text
The Weeknd
```

3. Подожди примерно полсекунды.
4. Появятся результаты YouTube.
5. Нажми на трек.
6. Откроется YouTube-плеер.
7. Нажми ▶, если браузер не разрешил автоматическое воспроизведение.

Никаких ссылок вставлять не нужно.

---


Потом останови сервер:

```text

```

и снова:

```bat
npm start
```

---

# 11. Если пишет "Ошибка поиска"

Проверь:

### Node.js

```text
node --version
```

### Сервер

В CMD должно быть:

```text
SOUNDSCAPE запущен: http://localhost:3000
```

### API

В Google Cloud должно быть включено:

```text
YouTube Data API v3
```

### API key

Проверь, что ключ настоящий и не содержит лишних пробелов.

---

# 12. Если YouTube пишет про квоту

YouTube Data API использует квоту.

Если квота закончилась, поиск через API перестанет возвращать результаты до обновления квоты.

Это не ошибка дизайна SOUNDSCAPE.

---

# 13. Если музыка не играет

Если результат поиска появляется, но видео не стартует:

1. Нажми ▶ в плеере.
2. Посмотри, нет ли сообщения от YouTube.
3. Некоторые видео могут быть недоступны для встраивания владельцем.
4. Попробуй другой результат.

Важно: SOUNDSCAPE использует официальный YouTube Player, а не скачивает аудио с YouTube.

# 🛠️ Если в старой V2 кнопки не нажимались

В первой V2 была моя ошибка в сборке HTML: код YouTube случайно попал внутрь
`<script src="...">`, поэтому браузер мог неправильно разобрать страницу и
JavaScript кнопок не запускался.

В этом исправленном архиве это уже починено.

Также исправлена разметка блока Beat Composer и добавлены правила, чтобы
декоративный космический фон не перехватывал клики.

Если у тебя открыта старая версия, полностью закрой вкладку и запусти новую.
